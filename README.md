# 🪨 Rock, Paper, Scissors – Python Console Game

A fun and interactive command-line game built with Python, where you play Rock, Paper, Scissors against the computer.

## 🎮 Features

- Input validation to ensure correct choices
- Random computer moves using `random` module
- Score tracking across multiple rounds
- Replay option with final score summary
- Cross-platform console clearing for better UX

## 🛠️ Technologies Used

- Python 3
- Standard libraries: `random`, `os`
